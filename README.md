# SIRIUS Contao Theme – Ein Onepager Theme für Contao

**Erstelle eine hochwertige Contao Website in weniger als einem Tag. So schnell war deine Kundschaft noch nie online.**

Du möchtest einen Onepager mit Contao realisieren? Dann ist das SIRIUS Theme genau das richtige für dich. Mit SIRIUS erstellst du in kürzester Zeit einen Onepager mit Contao und machst nicht nur deinen Kunden und deine Kundin, sondern auch deinen Geldbeutel glücklich.

SIRIUS basiert auf dem [Nutshell Framework](https://github.com/nutshell-framework) und wurde in Version 3 speziell für Contao 5.7 LTS entwickelt. Das Theme ist für alle gängigen Geräte (Smartphones, Tablets, Desktop) und Browser (Chrome, Firefox, MS Edge, Safari) optimiert.

Das Onepage Theme SIRIUS ist perfekt geeignet für:

- Handwerker:innen
- Startups
- kleine Geschäfte
- Ärzte/Ärztinnen und Apotheken
- Aktionen
- Produktveröffentlichungen
- Affiliate Seiten

Und wenn sich das Unternehmen weiterentwickelt, lässt sich aus dem Onepager auch eine vollwertige Contao Website mit Unterseiten machen.

HIGHLIGHTS:

- einfache Installation über den Contao Manager oder das Contao Backend
- Farben, Schriften und Abstände über den Theme Editor der Theme Toolbox anpassbar
- drei mitgelieferte Farbwelten: Waldgrün, Terrakotta und Schiefer
- vielseitige Anpassungsmöglichkeiten über SCSS
- Gestaltung aller Standard-Inhaltselemente
- Onepage-Navigation mit Sprungmarken
- keine Copyright- oder Backlink-Pflicht notwendig
